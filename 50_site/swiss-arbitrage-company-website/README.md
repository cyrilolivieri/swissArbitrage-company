# swiss-arbitrage-company-website

Projet OpenCodeBMAD pour swissarbitrage dans le domaine 50_site.

## Lancer le build

```bash
cd /home/cyril/swissarbitrage-company/50_site/swiss-arbitrage-company-website
opencode run "bmad-build-auto"
```

## Structure

- `.agents/skills/` : skills BMAD
- `_bmad-output/` : livrables du projet
- `docs/` : connaissance projet
- `_bmad/` : runtime BMAD
